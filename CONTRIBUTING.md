# u3oko
## Глоссарий
- КМП - компонент исходного кода
- ЫЫ - ыскусственный ыдиот

### Требования к организации кодовой базы
- Весь код поделен на компоненты далее КМП
- КМП на верхнем уровне это {приложение/статическая библиотека/динамическая библиотека}
- КМП на промежуточном это некий выделенный функционал с интерфейсом взаимодействия
- Интерфейс КМП разделяется на внутренний и внешний
- Внутренний интерфейсный файл КМП может включать себя только внешние интерфейсные файлы других КМП-ов
- Единицы компиляции КМП не должны включать в себя ничего кроме внутреннего интерфейсного файла КМП и опционально интерфейса данной единицы компиляции

### Требования к оформлению файлов КМП
- Поля заголовка
    - file, имя файла для быстрого его поиска через обычный механизм ОС
    - author, имя автора
    - date, дата создания файла
    - copyright
    - [original],  URL указывает на источник исходного кода
    - [ai-generator], если использовался ЫЫ при создании или модификации кода
    - [ai-prompt], промпт для ЫЫ, который использовался для генерации кода

### Требования к именам файлов и их размещению
- Имена файлов и каталогов в нижнем регистре
- Каждой namespace представляет собой каталог
- Иерархия каталогов должна совпадать с иерархией namespaces
- Каждый КМП находится в отдельном namespace
- Файлы типов лежат в каталоге того namespace, которому они принадлежат
- Вспомогательные файлы сборки (cmake) должны лежать в верхнем каталоге КМП, которому они принадлежат, опционально в отдельном подкаталоге _make
- Вспомогательные файлы документации должны лежать в верхнем каталоге КМП, которому они принадлежат, опцинально в отдельном подкаталоге _docs
- Файлы тестов в отдельном каталоге ut в том каталоге, функционал которого они покрывают. Тесты являются частью документации
- Маска файлов enum: ```[enum]-name-enum.cpp, [enum]-name-enum.hpp```
- Маска файлов class/type/union: ```name-type.cpp, name-type.hpp```
- Маска файлов free functions: ```name-family-[funcs].cpp, name-family-[funcs].hpp```
- Маска файлов defines: ```[defines]-name-family-defines.cpp```
- Маска синонимов КМП: ```name-component-[syn].hpp```
- Маска констант КМП: ```name-component-[const-vals].cpp, name-component-[const-vals].hpp```
- Маска внешнего интерфейса КМП: ```name-component-[includes].hpp```
- Маска внутреннего интерфейса КМП: ```name-component-[includes_int].hpp```

### Требования к именам переменных, функций, типов
- Имена функций в нижнем регистре через подчеркивание ```this_name_func```
- Имена всех переменнных/аргументов в нижнем регистре через подчеркивание ```this_name_variable```
- Имена переменных типа также должны заканчиваться символом _ ```this_name_variable_```
- Имена типов в стиле UpperCamelCase /ThisMyClass/
- Имена defines в верхем регистре через подчеркивание и начинаются с префикса U3_ ```U3_THIS_EXAMPLE_DEFINE```
- Имена аргументов шаблона начинаются с префикса T, далее по шаблону имени типа ```TTemplateType```
